The World in One Day — a program that draws 26 November 2026's world news as one dense, dated newspaper front page (1024x1024 PNG): 27 stories, 10 regions, 14 fields, a UTC timeline and a markets strip. Every story was verified from live news reports on 26 November 2026 and is hardcoded in `main.py`; the program uses only the Python 3 standard library, makes no network calls, and writes byte-identical output on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes exactly one file, `out/entry.png` (1024x1024, under 1 MiB).
